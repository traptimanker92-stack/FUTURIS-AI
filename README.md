# Futuris 🚀
> **AI-Powered Career & Future Simulator** — An advanced career path ecosystem built for students, career switchers, and higher education aspirants.

---

## 🌟 About
**Futuris** is an all-in-one AI-powered career guidance and professional growth web application. Inspired by advanced hackathon problem statements, it moves beyond static career quizzes to simulate realistic career trajectories complete with year-by-year milestones, skill gaps, dynamic timelines, interactive task trackers, custom focus tools, a creative ATS resume builder, and live interview prep.

---
